# Updating sorin-art.com

All content lives in `_build/content.py`. The site is generated by `_build/build.py`
into the repository root, which GitHub Pages publishes as https://sorin-art.com.

## Add a progress update to a work-in-progress project

1. Put new photos in `_build/media/<project-slug>/` (this folder is not uploaded; only the resized copies are).
2. In `content.py`, add an entry to the project's `"log"` list:

   ```python
   "log": [
       {"date": "2026-10-28", "title": "First printed cuff",
        "text": ["What changed today, in a few sentences."],
        "images": ["media/tremor-glove/cuff-01.jpg"]},
   ],
   ```
3. Run `python3 _build/build.py` from the repository root, check `index.html` in a browser, then commit and push.

Updates show newest first on the project page, and the project card on the home page shows the date of the latest update.

## Add a new project

Copy an existing entry in `PROJECTS`, give it a new `slug`, set `group` to one of the
groups in `GROUPS` (`"in-progress"` for unfinished work), and point `cover` and
`gallery` at image keys (`media/...` paths for new photos).

## Requirements

Python 3 with Pillow (`pip install pillow`).
